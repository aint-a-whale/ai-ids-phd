# AI-Based Intrusion Detection System (PhD Research)

This repository contains the core codebase for my PhD research on **AI-driven Intrusion Detection Systems (IDS)**.  
The focus is on **unsupervised** and **semi-supervised** learning methods for **anomaly detection** and **cybersecurity** in intelligent and onboard systems.

---

## 🚀 Project Overview
The goal is to design and evaluate machine learning models capable of:
- Detecting anomalies without labeled data  
- Operating in real time on embedded or edge devices  
- Enhancing the security of autonomous and aviation systems  

---

## 🧩 Repository Structure
src/ # Main source code (models, training, evaluation)
configs/ # Experiment configurations
results/ # Lightweight experiment logs and metrics
docs/ # Research notes and reading list
scripts/ # Utility scripts for training and evaluation
